# Offerta — arayüz (GitHub Pages)

Bu depo yalnızca Offerta'nın arayüz dosyalarını içerir; gizli bilgi yoktur.
API: https://offerta.serdox.workers.dev (ayrı, özel depo: `offerta`).

Yayın: `main` dalına push edilince GitHub Pages otomatik yayınlar.
Veri aktarımı bittikten sonra `aktar.html` dosyasını silebilirsiniz.
